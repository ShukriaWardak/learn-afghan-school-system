# Classes register
Select the database configured for the dashboard before importing 009_class_register.sql. Refresh check-setup.php and look for class_register.
Super admins can add and edit sections by branch, academic start year (Gregorian), grade (1–12) and section. Use inactive status to retire a section. Branch and zone admins can view their assigned scope. This version does not assign individual students or teachers or create timetables.
